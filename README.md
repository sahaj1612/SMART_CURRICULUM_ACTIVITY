# Smart Curriculum Activity

Smart Curriculum Activity is a student activity and attendance-oriented web interface built as a concept project with multiple pages for timetable viewing, task flow, attendance, suggestions, and related campus utilities.

> Status: This project is only a prototype / dummy version.

## Tech Stack

- Node.js
- Express
- EJS
- HTML
- CSS

## Included Pages

- Home page
- Attendance pages
- Live attendance
- Suggestions and survey flow
- Counsellor flow
- QR page
- Daily routine
- Time table
- Task display
- Face recognition screens

## Run Locally

```bash
npm install
npm start
```

Then open `http://localhost:8080`.

## Note

The current version is mainly for demonstration and UI flow purposes. Data is hard-coded, and full backend/database functionality is not implemented yet.
